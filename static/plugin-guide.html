Optional plugins

ATLAS starts with Juniper and voice chat ready to set up. Optional plugins start uninstalled and off. In Plugins → Marketplace, select Install. This registers the bundled plugin without running it. Configure it, then use its switch in Installed to enable it. Installing or saving a key never enables a plugin. Saved choices survive application updates.

“Ready to enable” checks local configuration. It does not prove that an internet service is online or that your account has credit. Test connection runs only when you press it. Planned entries cannot be installed.

PluginSetup and use
Web searchAdd your own Exa or Brave API key and test it. Choose that provider or Auto. There is no keyless search fallback. Queries go to the chosen service.
Eyes (screen)Choose a model with confirmed image support, enable the plugin, then turn Eyes on in the dashboard. Choose your monitor in Configure. A text-only model cannot use screenshot Eyes.
Live screenRequires Eyes on and a remote vLLM deployment with the live watcher configured. The standard local Ollama setup and cloud chat APIs do not supply that service. Configure the program to watch. Test connection reports whether capture is working.
Think while listeningRequires a remote vLLM deployment with ATLAS two-stage inference enabled. It cannot run on the standard local or cloud chat API setup.
Date & timeNo account required. Ask for the time in a city or timezone. Configure and test a timezone.
LanguagesChoose automatic detection or one input language and your main reply language. Speech support depends on the selected transcription and voice models.
Dice, coins & polls; Timers & remindersNo account required. Ask for a roll, start a vote or set a timer. Timers are announced while ATLAS is running and the plugin is enabled.
Weather; Game infoRequire internet access to Open-Meteo and Steam respectively. No key required. Configure your location/units or store region, then Test connection.
Call summary; Floor referee; Room-energy senseUse the current session transcript. Ask for a recap, talk-time balance or a topic. Room-energy sense adjusts tone. There is no historical transcript when a fresh session begins.
Teach-me mode; Lore keeperAsk ATLAS to learn a lesson or add group lore. Stored per agent locally. Lore waits for approval by default; review it in Configure.
Notes & follow-ups; Step back; Self-checkNo extra service required. Ask for a note, a pause or a prediction check. Source inspection is read-only and restricted to ATLAS files.
Quiet fact-checkInstall, configure and enable Web search first. Searches may use credits. Configure daily limits and background checking; results appear in Configure.
Live translate; Soul reflectionUse the model selected in Settings. Translation needs a transcript line. Reflection needs a finished recorded call; approve or reject its proposed notes. The model provider may charge for these requests.
Highlight reelRequires a finished recorded call. Find moments in Configure. Listing does not require FFmpeg; rendering caption cards requires FFmpeg on PATH and the consent setting. No clips are made automatically.
Nemotron diarizationRequires an NVIDIA CUDA GPU and a separate Python environment with CUDA-capable PyTorch, NumPy, packaging and transformers ≥ 5.18. Enter that environment’s full Python executable path in Configure and save, then Test connection. Use the PyTorch installation selector for the correct CUDA build. Enabling downloads/loads nvidia/Nemotron-3-Diarization on first use. Model access and internet are required for the first download; base voiceprints remain available if it fails.
